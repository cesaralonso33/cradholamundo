# Matriz funcional actual

Inventario observado en frontend router y rutas Fastify. Los permisos de la UI no sustituyen autorización backend. Administración indica guardas observadas en handler; el control por módulo se evalúa además en permisos.

| Ruta UI / pantalla | API / operaciones | Acceso observado | Funciones |
|---|---|---|---|
| `/login` Login | `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/2fa/complete`, `POST /api/auth/logout`, `GET /api/auth/me`, `POST /api/auth/2fa/setup`, `POST /api/auth/2fa/verify`, `POST /api/auth/2fa/disable` | Login y completar 2FA sin `preHandler`; register `authenticate` + `requirePermission("users")`; me/setup/verify/disable `authenticate`; logout sin guard | Login, registro, sesión, cierre y administración 2FA |
| `/` Inventory | `GET/POST /api/products`, `GET/PUT/DELETE /api/products/:sku`, `POST /api/products/:sku/archive`, `GET /api/products/:sku/history`, `POST /api/inventory/movement` | GET/POST/product/history/movement: `authenticate` + `requirePermission("products")`; archive/PUT además limita a admin o propietario de ubicación; DELETE `authenticate` + `adminOnly` | captura, consulta, edición, movimiento, archivo e historial |
| `/history` History | `GET /api/products/:sku/history` | `authenticate` + `requirePermission("products")` (ruta UI requiere history) | historial de ubicación paginado |
| `/users` Users | `GET /api/users`, `PUT/DELETE /api/users/:id` | `authenticate` + `requirePermission("users")`; reglas adicionales de último admin y autoeliminación | consulta, edición y eliminación de usuarios |
| `/roles` Roles | `GET /api/permissions`, `GET/POST /api/roles`, `PUT/DELETE /api/roles/:id`, `GET /api/roles/options` | permissions y roles CRUD: `authenticate` + `adminOnly`; options: `authenticate` + `requirePermission("users")` | roles y permisos |
| `/employees` Employees | `GET/POST /api/employees`, `GET /api/employees/:id`, `DELETE /api/employees/:id`, `POST /api/employees/import`, `GET/POST /api/employees/:id/constancias`, `DELETE /api/constancias/:id` | GET/POST employees, GET id, constancias GET/POST: `authenticate` + `requirePermission("employees")`; DELETE employee, import y DELETE constancia: `authenticate` + `adminOnly` | consulta y creación de empleados, import Excel, consulta/creación/eliminación admin y adjuntos |
| `/papeleria` Papeleria | `GET/POST /api/papeleria`, `PUT/DELETE /api/papeleria/:id`, `POST /api/papeleria/import`; `GET/POST /api/papeleria/orders`, `GET/PUT /api/papeleria/orders/:id`, `POST /api/papeleria/orders/:id/close` | GET catálogo y GET/POST orders, GET order: `authenticate` + `requirePermission("papeleria")`; POST catálogo, PUT/DELETE artículo, import, PUT order, close: `authenticate` + `adminOnly`; no-admin ve solo sus propios pedidos | consulta y mantenimiento admin de artículos, importación, pedidos y cierre |
| `/settings` Settings | `GET/PUT /api/settings`, `GET/POST/DELETE /api/settings/api-key`, `PUT /api/settings/api-enabled` | settings GET/PUT: `authenticate` + `requirePermission("settings")`; API key y enabled: `authenticate` + `adminOnly` | configuración y API key |
| `/audit` Audit | `GET /api/audit-logs` | `authenticate` + `adminOnly` | auditoría filtrada/paginada |
| `/api-docs` ApiDocs | Pantalla documentación API; además `GET /api/permissions` en la API (sin operación de edición en esa pantalla declarada aquí) | ruta UI requiere permiso `api`; `GET /api/permissions` exige `authenticate` + `adminOnly` | consulta de documentación |
| — | `GET /health`, `GET /api/health` | sin auth | health y estado DB |
| — | `GET /api/backup`, `POST /api/backup/restore` | `authenticate` + `adminOnly` | exportación/restauración JSON; restore limita body a 50 MiB |

Importaciones: `POST /api/employees/import` y `POST /api/papeleria/import`, ambas `authenticate` + `adminOnly`, Excel. Exportación: `GET /api/backup`, `authenticate` + `adminOnly`; excluye archivos físicos de constancias según README. Adjuntos: `POST /api/employees/:id/constancias`, `authenticate` + `requirePermission("employees")`, multipart, extensión permitida, guardados en volumen uploads; eliminación con `DELETE /api/constancias/:id`, admin. La matriz registra métodos y guards declarados en los handlers; las restricciones de propiedad/reglas de negocio se indican separadamente. Sin inventario separado de botones UI por falta de pruebas visuales; las pantallas están identificadas en router.
